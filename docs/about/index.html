About

OpenGDD is an open format for game design documents. Prose carries the designer's creative intent. Structured data supports validation. Authority levels state which decisions stay fixed, which belong to the builder, and which are resolved separately for each build. The specification prose is licensed CC-BY 4.0. The validator, the authoring tool, and this site are licensed MIT.

Stewardship

The specification is stewarded by Starphase Lab, a software and production company. It maintains the format, the conformance suite, and this site.

OpenGDD is published at opengdd.org. The source repository for the core specification is github.com/opengdd/core-spec.

Privacy

This site counts visits with GoatCounter. It sets no cookies. A visit records the page, referrer, browser, operating system, screen width, language, and country. IP addresses are never stored. Repeat visits are grouped with a random identifier held only in memory for at most eight hours. See GoatCounter's privacy policy.

GoatCounter is the only outside service this site contacts. Everything else, including the fonts, is served from opengdd.org. Theme preferences and drafts in the authoring tool stay in your browser and are never sent anywhere.
