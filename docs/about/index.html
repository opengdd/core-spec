About

OpenGDD is an open format for game design documents. It helps a designer describe a game and guide the people building it. The project maintains the specification, an authoring tool, the validator, and documentation.

OpenGDD is a working draft. Its source is available in the public specification repository. The evolution page explains how changes are proposed and reviewed.

Privacy

This site uses GoatCounter to count visits without setting analytics cookies. It collects page and referrer information, browser and operating-system details, screen width, language and country.

GoatCounter recognizes repeated visits with a temporary value in memory. That value comes from the site, the IP address and browser information. It lasts up to 8 hours. IP addresses are not saved in its analytics database. Its privacy policy explains how it stores counts and optional pageview records.

Fonts are served from opengdd.org. Your theme choice and your work in the authoring tool stay in this browser. The tool uploads nothing.
