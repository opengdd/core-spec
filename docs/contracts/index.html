Contracts catalogue

Start with the questions your game must answer

contracts help you design your game's logic almost effortlessly, while you focus on creative prose.

A contract is a reusable set of decisions for a familiar game mechanism. Browse the questions in a readable form, inspect the exact JSON, and download the unchanged core when you need it.

A publishing channel, not a registry. This catalogue makes contract cores findable and reviewable. It does not make one authoritative by listing it. A game binds to the exact core it vendors in its own package. Read how contracts fit into an OpenGDD package.
