An afternoon spec

Start here: a complete five-file example.

You already know Snake. This chapter shows excerpts from a complete five-file spec. You know every rule already, so you can watch where the format puts each one. When you are ready to work from real files, download Garden Snake as a zip or open the complete package.

the complete package on disk

garden-snake/
  manifest.json     who and what this is
  tuning.json       the numbers
  01-overview.md    fantasy, pitch, and presentation choices
  02-mechanics.md   the rules
  05-build-plan.md  phases, and the tests

the fantasy block, opening 01-overview.md

You are a garden snake with an appetite bigger than the garden, growing longer with every fallen apple until there is no room left for you.
Feel: hungry, tidy, inevitable.
NOT: violent, rushed, cluttered.

a rule, from 02-mechanics.md

Time advances in steps of `snake.tick_seconds`. Each tick, the
head moves one cell in the current direction, the body follows,
and the tail cell empties.

After every `snake.speedup_every_apples` apples eaten in the current
run, later ticks become `snake.speedup_step_seconds` shorter, down to
`snake.minimum_tick_seconds`.

tuning.json, complete

{
  "tunables": {
    "snake.tick_seconds": 0.4,
    "snake.speedup_every_apples": 5,
    "snake.speedup_step_seconds": 0.025,
    "snake.minimum_tick_seconds": 0.15
  },
  "constants": {
    "garden.size": 13,
    "snake.start_length": 3
  },
  "meta": {
    "snake.tick_seconds": { "range": [0.3, 0.8] },
    "snake.speedup_every_apples": { "range": [2, 12] },
    "snake.speedup_step_seconds": { "range": [0.01, 0.05] },
    "snake.minimum_tick_seconds": { "range": [0.1, 0.2] }
  }
}

one of the four tests, from 05-build-plan.md

{
  "type": "scenario",
  "given": "a run in progress with the head one cell from the apple",
  "when": ["the head moves onto the apple", "play continues until the head moves into the wall", "a fresh run continues until the head moves into the snake's own body"],
  "then": ["eating grows the snake by one cell, scores one apple, and a new apple appears in an empty cell", "the wall ends its run on the spot", "the body ends its run on the spot", "each finished run reports its apple count"],
  "diagnostics": ["tick-log", "garden-before-after"]
}

In plain language, the test covers eating and both collisions. Eating grows the snake and increases the score. Either collision ends the run, which then reports the number of apples eaten.

What to notice:

  • The rules are prose. You describe Snake the way you would describe it to a friend.
  • The numbers live in tuning.json, and prose cites the key, never the number. Change the value once and every reference remains correct.
  • meta.range records the minimum and maximum allowed for each adjustable value.
  • Four tests state the results a build must demonstrate without prescribing its implementation.
  • The fantasy block sets the intended feeling. The overview gives the builder presentation choices while keeping gameplay fixed.

The linked five-file package is complete. Validation reports no errors or warnings. Later chapters marked Opt-in describe features you add only when the game needs them.
