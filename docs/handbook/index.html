The handbook

The handbook is where the format starts to make sense as a whole: what each part is for, and how the parts fit together. Read the get-started guide to write your first spec; read this to understand what you wrote; read the specification when you need the exact rule. Each chapter stands alone, so start anywhere.

1. The shape of a spec

Your whole design fits in one folder, and you can hand that folder to anyone. A spec is one folder that holds the whole design at once.
