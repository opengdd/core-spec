The handbook

Come here with a design question. Each short chapter shows what one part of OpenGDD gives you, where it lives, and how to use it. Start with the get-started guide when you want to make a first package, or open the group that matches the work in front of you. The specification remains the exact rulebook.

Content, links, and time

Organize repeated content, connect records, name changing values, and describe how time passes.

Collections

Games are full of lists: technologies, recipes, cards, levels. A collection keeps one kind of content in one folder, with one JSON file per item.

Links

A link is a field holding another record's id. It connects items in your collections and lets validation report a missing target where the link is defined.
